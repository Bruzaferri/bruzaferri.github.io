Política de privacidad

Hermes — aplicación de uso personal

Esta aplicación es de uso exclusivamente personal de su propietario. No se distribuye ni está disponible para terceros.

Qué datos se consultan

Con el consentimiento expreso del propietario de la cuenta, la aplicación usa las API de Google para leer y enviar correo (Gmail), leer y crear archivos (Drive), gestionar eventos (Calendar), editar hojas de cálculo y documentos (Sheets y Docs), consultar contactos (solo lectura) y gestionar tareas (Tasks). Siempre sobre la cuenta del propio propietario y solo con los permisos que él autoriza en la pantalla de consentimiento de Google. El acceso al Drive es de lectura y de creación de archivos propios: la aplicación no puede borrar, mover ni compartir los archivos existentes del propietario.

Dónde se guardan

En ningún servidor. El token de acceso OAuth se guarda únicamente en el disco local del equipo del propietario. No existen servidores propios ni de terceros que reciban esa información.

Con quién se comparte

Con nadie. No hay analítica, publicidad ni cesión de datos a terceros. Los datos no se venden ni se usan para entrenar modelos.

Conservación y revocación

El propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions, lo que invalida el token guardado en el equipo. También puede borrar el archivo local del token para eliminar el acceso de inmediato.
